"ftrace" script to trace kvm_vm_ioctl() kernel call, while starting a VM:

############################################################
echo kvm_vm_ioctl > /sys/kernel/tracing/set_graph_function
echo function_graph > /sys/kernel/tracing/current_tracer

cat /sys/kernel/tracing/trace_pipe > /tmp/ftrace.out &
## start kernel  tracing
echo 1 > /sys/kernel/tracing/tracing_on

virsh start anolis231-nosev-1
## stop tracing
echo 0 > /sys/kernel/tracing/tracing_on

############################################################


Run this script on a host [ where you can create a VM ] & check /tmp/ftrace.out
You can enter the function you want to trace by entering:
echo <my kernel function > /sys/kernel/tracing/set_graph_function 

Using ftrace you can check whether your backported patches new calls are invoked, where the qemu call fails inside
the kernel and so on...without the need of  "printk()" ,rebuilding kernel & rebooting host...
