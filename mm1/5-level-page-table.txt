To check if 5-level paging is enabled in Linux, you can use the command lscpu | grep -i la57. If the output contains la57, then 5-level paging is supported by the CPU.
 Additionally, you can verify kernel support by checking the kernel configuration file for CONFIG_X86_5LEVEL=y
