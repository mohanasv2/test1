Steps [ on 9f6e system ]
############################
1) Identify free disk on Host
   lsblk

2) Find the device PCI details:  [ example /dev/nvme0 disk ]
    [root@volcano9f6e-hostos ~]# dmesg| grep nvme0
    [    8.076880] nvme nvme0: pci function 0000:02:00.0
    [    8.103675] nvme nvme0: Shutdown timeout set to 10 seconds
    [    8.174032] nvme nvme0: 129/0/0 default/read/poll queues

3) get PCI device entry:
   virsh nodedev-list | grep pci 

   ....
   pci_0000_02_00_0    ====> [ nvme nvme0: pci function 0000:02:00.0 ]

4) Detach the device from host:

  virsh nodedev-dettach pci_0000_02_00_0   [ reattaching: virsh nodedev-reattach pci_0000_02_00_0 ]

 
5) Add the following entry into VM xml config: [add a device entry in the <devices> section to attach the PCI device to the guest ]

  <hostdev mode='subsystem' type='pci' managed='yes'>
    <source>
      <address domain='0x0000' bus='0x02' slot='0x00' function='0x0'/>
    </source>
  </hostdev>

6) restart the guest

7) check trace:
 
 echo 1 > tracing_on
 tail -f trace
 echo 0 > tracing_on
