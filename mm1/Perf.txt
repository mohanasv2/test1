
Perf => monitor H/W (PMU) & S/W events  , trace program execution, profiling


perf list => show all events supported by 


PMU driver on Linux (Ubuntu): ls /sys/bus/event_source/devices

PMU events supported for the CPU: ls /sys/bus/event_source/devices/cpu/events


The max no of PMU events that can be specified to perf stat command:

The available counters of PMU for each CPU are limited [ for example 6 PMC counters per cpu thread ]
If events selected in the Perf command exceed the available counters, the kernel uses time multiplexing to 
give each event a chance to count.

example:
 perf stat with 6 PMU events [ latest AMD/Intel cpus support 6 PMC counters per thread.. if we specify 6 events, then each
 one PMC counter per event used]
