KVM installation:

Ubuntu:
#################################
 sudo apt-get install qemu-kvm libvirt-clients libvirt-daemon-system bridge-utils virt-manager

  ARM:
    sudo apt install qemu-system-aarch64 qemu-efi-aarch64 libvirt-daemon-system virt-manager

  Note:
   If virt-manager not connecting, check the following:
   sudo usermod -aG libvirt $(whoami)
   systemctl status virtqemud
   sudo systemctl enable --now virtqemud.socket
   sudo systemctl enable --now virtqemud.service

   disable selinux: sudo setenforce 0
###################################

VM disk resize:

from Host:

stop the VM first
# getting the path of the VMs image file
 sudo virsh domblklist mohandev

# get more info on thee VM image file
  sudo qemu-img info /var/lib/libvirt/images/mohandev.qcow2

# getting the snapshots of the VM
 sudo virsh snapshot-list mohandev

# delete any snapshots using below cmd:
 sudo virsh snapshot-delete

#resizing the VMs image file
 sudo qemu-img resize /var/lib/libvirt/images/mohandev.qcow2 +100G

# run info on the image
 sudo qemu-img info /var/lib/libvirt/images/mohandev.qcow2  => will show the new size

Now start the VM 

from VM:

run lsblk  & check whether new size reflects . And also find the LV/partition hosting the root FS

sudo lsblk  => check partition, which you want to increase [ normally the one hosts /root FS ]

sudo growpart /dev/vda 3   // increase partition size

sudo pvresize /dev/vda3    // increases PV size

sudo lvextend -r -l +100%FREE /dev/mapper/ubuntu--vg-ubuntu--lv  // extend LV hosting the root

sudo resize2fs  /dev/mapper/ubuntu--vg-ubuntu--lv
