Making HD Drive as bootable disk:

Method 1: Make a whole NVMe disk as  a Bootable Installer:
If the NVMe disk is dedicated to installation media, write the ISO directly:

dd if=AnolisOS.iso of=/dev/nvme1n1 bs=64M status=progress oflag=sync

Then select that NVMe device from the UEFI boot menu.

Method 2: Make an NVMe disk partition as a Bootable Installer:

suppose:

nvme0n1p1   EFI System Partition
nvme0n1p2   Existing OS
nvme0n1p3   Installer Partition (20-30GB)
nvme0n1p4   Data
Steps:
mkfs.ext4 /dev/nvme0n1p3
mount /dev/nvme0n1p3 /mnt/install

mount -o loop Anolis.iso /mnt/iso

cp -a /mnt/iso/* /mnt/install/
sync

Grub entry: [ in /etc/grub.d/40_custom ]
menuentry "Anolis Installer" {
    search --fs-uuid --set=root <UUID-of-nvme0n1p3>

    linuxefi /images/pxeboot/vmlinuz \
        inst.stage2=hd:UUID=<UUID-of-nvme0n1p3>

    initrdefi /images/pxeboot/initrd.img
}

 [ blkid /dev/nvme0n1p3  ==> UUID ]
