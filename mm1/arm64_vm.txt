
1. download cloud image from : https://cloud-images.ubuntu.com/jammy/20250207/
  
 https://cloud-images.ubuntu.com/jammy/20250207/jammy-server-cloudimg-arm64.img

2. create a dummy arm64 vm using virt-manager [ during install it will hang, now shutdown it ]

3. replace the qcow2 image in the dummy arm vm's xml file, with the downloaded jammy-server-cloudimg-arm64.img.

[ before using the cloud image, set the root password in the image as below ]

virt-customize -a jammy-server-cloudimg-arm64-2.img --root-password password:amd1234

[ run as root user ]
