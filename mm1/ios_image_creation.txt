1) mount -o loop <original ISO > /mm1

2) mkdir /new_iso

3) cp -aR /mm1/* /new_iso/

4) cd /new_iso; rm -rf os/P*/<unwanted rpms>

5) ## iso image creation command. "." at the end of the command is important !!!, without that it won't work
    yum install genisoimage  [ which installs mkisofs command ]

    mkisofs -o /home/amd/a231_new_dvd.iso -b isolinux/isolinux.bin -J -R -l -c isolinux/boot.cat -no-emul-boot -boot-load-size 4 -boot-info-table -eltorito-alt-boot -e images/efiboot.img -no-emul-boot -graft-points -V "Anolis 23.1 Server.x86_64" .

6) Convert the ISO image to be compatible for a USB boot image:

    isohybrid -uefi <new iso image created in step 5>

website:  https://www.redhat.com/sysadmin/optimized-iso-image
