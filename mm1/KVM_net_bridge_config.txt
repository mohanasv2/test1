After bringingup Bridge, we need to configure Network for KVM [ using virsh ]

1) Create a xml file as below:

cat /tmp/kvm_net.xml
##################################
<network>
  <name>br0</name>
  <forward mode="bridge"/>
  <bridge name="br0" />
</network>
##################################

2. Then run the following to configure the network for virtualization:

cat /tmp/kvm_net.sh
####################
virsh net-define /tmp/kvm_net.xml
virsh net-start br0
virsh net-autostart br0
virsh net-list --all
