Enabling 1GB & 2MB huge pages :

Host side:

1) Check whether H/W supports huge page: 
    lscpu | grep pdpe1gb

2) Enable huge page through Linux boot command line

  In /etc/default/grub, add the following line: 
  GRUB_CMDLINE_LINUX="default_hugepagesz=1G hugepagesz=1G hugepages=64 hugepagesz=2M hugepages=32768"

  Then run update-grub or grub2-mkconfig -o <grub file> based on the distro

3) Reboot the host

4) cat /proc/cmdline
BOOT_IMAGE=(hd1,gpt2)/vmlinuz-6.6.102-pstate-ph1-test root=/dev/mapper/ao_anolis-root ro resume=/dev/mapper/ao_anolis-swap rd.lvm.lv=ao_anolis/root rd.lvm.lv=ao_anolis/swap rhgb quiet amd_pstate=active default_hugepagesz=1G hugepagesz=1G hugepages=64 hugepagesz=2M hugepages=32768


5) Check Huge page allocation through /proc/meminfo

  cat /proc/meminfo | grep Huge
AnonHugePages:    983040 kB
ShmemHugePages:        0 kB
FileHugePages:         0 kB
HugePages_Total:      64
HugePages_Free:       64
HugePages_Rsvd:       0
HugePages_Surp:        0
Hugepagesize:    1048576 kB
Hugetlb:        134217728 kB
root@volcano9f8e-oshost:~#

6)
# mkdir /dev/hugepages1G
# mount -t hugetlbfs -o pagesize=1G none /dev/hugepages1G
# mkdir /dev/hugepages2M
# mount -t hugetlbfs -o pagesize=2M none /dev/hugepages2M

7) service restart libvirtd

 [ Check  /sys/devices/system/node/node0/hugepages/hugepages-2048kB/nr_hugepages & /sys/devices/system/node/node1/hugepages/hugepages-1048576kB/nr_hugepages ]

Guest side:


1G huge page size guest:

1) Enable huge page through /etc/default/grub

 GRUB_CMDLINE_LINUX="resume=/dev/mapper/ao_anolis-swap rd.lvm.lv=ao_anolis/root rd.lvm.lv=ao_anolis/swap rhgb default_hugepagesz=1G hugepagesz=1G hugepages=8 quiet"

 Then run update-grub or grub2-mkconfig -o <grub file> based on the distro

2) Reboot the guest

3)  cat /proc/cmdline
BOOT_IMAGE=(hd0,gpt2)/vmlinuz-6.6.102-pstate-p2 root=/dev/mapper/ao_anolis-root ro resume=/dev/mapper/ao_anolis-swap rd.lvm.lv=ao_anolis/root rd.lvm.lv=ao_anolis/swap rhgb default_hugepagesz=1G hugepagesz=1G hugepages=8 quiet

2MB huge page size guest:
